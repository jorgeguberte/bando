## Frozen normative principles

- **`delivery != settlement != semantic incorporation`** — adapter delivery, ledger reconciliation and search-graph advancement have orthogonal lifecycles.
- **`SemanticGenerationValid != SettlementBindingValid`** — generation expiry blocks search-graph mutation but never discharges real-world spend reconciliation.
- **`semantic staleness does not erase settlement obligations`**
- **`BudgetScope accounting != IntentFrame ownership`** — the BudgetScope bounds the local search; ownership and conservation belong to the IntentFrame exclusively.
- **`StageLocal != semantic dispatch`** — reserving resources and writing the outbox consumes no fuel and records no visited nodes.
- **`transport retry != new semantic attempt`** — re-emissions of the same `request_id` preserve search counters and visitation metrics.
- **`visited = actual expansion history != successor dedup set`** — nodes enter visitation history only on real dispatch expansion; the same VisitKey may legitimately appear multiple times.
