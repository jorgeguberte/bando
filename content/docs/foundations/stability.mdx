SOMA uses explicit stability labels.

## FROZEN

The concept is part of the current minimal ontology. It does not mean immutable forever, but changes require an explicit architectural decision and a counterexample or implementation need.

## RESOLVED FOR CURRENT PHASE

The rule is precise enough for the next implementation or IR step.

It may reopen when:

- implementation exposes an ambiguity;
- a negative test fails;
- a counterexample breaks an invariant;
- a later lowering cannot preserve the rule.

<Callout type="warn" title="Not a proof">
Resolved-for-current-phase does **not** mean formally sound, complete, or production-safe.
</Callout>
